#### 周天
越秀公园 中山纪念馆 陈家祠 上下九步行街  永庆坊 沙面岛 （太古仓码头）圣心大教堂 北京路 大佛古寺  （越秀区 荔湾区）

- **10:00-12:30 越秀公园片区（起步，轻松散步）**：
    - 大巴下车越秀公园 → 越秀公园（五羊雕像、湖边散步） → 中山纪念堂（公园内步行5-10分钟，免费或小门票，建筑庄严）。
    - 通勤：全步行，公园大但不累。
    - 注意：这里空气好，早上人少，拍照美。
- **12:30-13:00 通勤 + 午饭准备**：
    - 地铁2号线（越秀公园站）转1号线（公园前站换乘）到陈家祠站（约20分钟）。
- **13:00-15:00 陈家祠 + 上下九 + 永庆坊（老西关核心）**：
    - 陈家祠（1小时，岭南雕刻震撼，必看） → 步行10分钟到上下九步行街（吃午饭/早茶，推荐广州酒家或点都德，虾饺肠粉超赞） → 步行15分钟或地铁1号线1站到长寿路，逛永庆坊（文艺墙绘、咖啡店，女生独游超适合慢慢拍）。
    - 通勤：步行为主，短距离。
    - 注意：上下九周末热闹，中午休息吃东西补能量。
- **15:00-15:30 通勤到沙面**：
    - 从永庆坊步行/地铁6号线（黄沙站附近）到沙面（10-15分钟）。
- **15:30-16:30 沙面岛（欧式散步，放松过渡）**：
    - 安静拍照，建筑美，女生最爱。
    - 通勤：地铁直达。
- **16:30-17:30 圣心大教堂（优先闭馆前，必须段）**：
    - 地铁6号线（沙面附近黄沙站或文化公园）到一德路站（约15分钟） → 步行5-10分钟到教堂。
    - 专注参观内部（哥特彩窗超震撼，安静祈祷或拍照），确保17:00前进去。
    - 注意：教堂内着装得体（别穿太露），安静不闪光灯；如果周末时段短，提前到。
- **17:30-21:00 北京路步行街 + 大佛古寺（晚上放松结束）**：
    - 从教堂步行10分钟或地铁1号线/6号线到公园前/北京路站 → 北京路逛街（购物、街头小吃、看千年古道玻璃地板） → 顺路去大佛古寺（惠福东路/六榕路附近，步行5-10分钟，看外观/灯光，或如果还开补内部）。
    - 这里吃晚饭/宵夜（云吞面、姜撞奶），买手信，回酒店超近。
    - 通勤：步行+短地铁。

这个路线超级顺：越秀（北）→荔湾（西）→沙面（西南）→一德路教堂（南）→北京路（东），结束正回酒店区。下午重点教堂不赶，晚上北京路热闹安全。

#### 周一
白云山 广州博物馆 广州塔

周一（博物馆+白云山）：早上去白云山（地铁2号线到白云公园或公交，登山/索道看景，空气超好） → 中午回越秀午饭 → 下午广州艺术博物院（二沙岛，艺术展） → 若时间够，地铁去广东省博物馆（珠江新城，镇馆之宝） → 晚上广州南站高铁回。
