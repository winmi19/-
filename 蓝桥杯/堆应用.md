# 堆  9 图论
```
#堆详情  （默认小堆顶）


from heapq import *

  

hq=[]

heappush(hq,5)

heappush(hq,9)

heappush(hq,11)

heappush(hq,12)

heappush(hq,13)

heappush(hq,15)

  

print(hq[0])

print(hq[5])

print(hq)

  

heappop(hq)   #括号里面要写

print(hq)
```
基础操作
```
heappush(hp,3)  #插入3
heappop(hp)  #弹出顶部   
#默认小堆顶
```

``` #大堆顶处理
nums=[15,13,9,5,11,12]

hq=[]

for x in nums:

    heappush(hq,-x)

  

print(-hq[0])

print(hq)

  

#弹出最大

heappop(hq)

print(-hq[0])

print(hq)
```


```
### 适用场景

- **堆**：
    - 优先队列：如任务调度、事件驱动系统，需频繁获取最高优先级任务。
    - 求 Top-K 问题：如从海量数据中找出最大的 K 个数，使用大小为 K 的小顶堆，时间复杂度 O(n log K)。
    - 动态数据流：数据不断流入，需实时维护最大/最小值，如滑动窗口最大值。
    - 图算法：如 Dijkstra 最短路径、Prim 最小生成树，需反复提取最小距离节点。
- **简单列表排序**：
    - 静态数据：数据一次性给定，需整体有序，如成绩单排序、商品按价格排序。
    - 后续无需频繁增删：排序后数据基本不变，只需按序访问。
    - 需要完整有序序列：如分页显示、二分查找等，必须整个列表有序。
```
