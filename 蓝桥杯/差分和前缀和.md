
差分
```
n, m = map(int, input().split())
diff = [0] * (n + 2)  # 多开一点防止越界

for _ in range(m):
    l, r, c = map(int, input().split())
    diff[l] += c      # 入口：从这里开始涨
    diff[r + 1] -= c  # 出口：从这里往后恢复原状

# 最后“收网”：求前缀和还原原数组
a = [0] * (n + 1)
for i in range(1, n + 1):
    a[i] = a[i-1] + diff[i]

print(*(a[1:]))
```

应用场景：
- **区间修改多**：要对某个范围内的数反复加减。
- **单点查询少**：你不需要在每次修改后立刻知道某个数是多少，只需要最后知道结果。
- **数据范围大**：$n$ 和 $m$ 达到了 $10^5$ 或以上。

def makep(a:list[int]):

    n=len(a)

    p=[0]*(n+1)

    for i in range(1,n+1):

        p[i]=p[i-1]+a[i-1]  #对a要往前移一个，单位索引

    return p
