列表转字符串：
"".join(list)
```

names = ['Python', 'Java', 'C++']
# 用空格粘合
s1 = " ".join(names)  # 结果: 'Python Java C++'

# 用逗号粘合
s2 = ",".join(names)  # 结果: 'Python,Java,C++'

# 直接粘合（无缝对接）
s3 = "".join(names)   # 结果: 'PythonJavaC++'
```

map：
	![[Pasted image 20260302114220.png]]

在你之前的图片例子中： `a, b, c = map(int, input().split())`
之所以没有报错，是因为你使用了**变量解包（Unpacking）**。当你把 `map` 对象赋值给固定数量的变量（`a, b, c`）时，Python 会强制要求 `map` 把里面的值一个个“吐”出来填满这些变量。

如果你直接打印它，你会看到类似 `<map object at 0x...>` 的东西，而不是你期待的 `[1, 2, 3]`。
