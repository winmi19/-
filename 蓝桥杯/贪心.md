
### 1. **零钱兑换问题 (Coin Change Problem)**

#### 题目：

给定一个数组 `coins`，其中每个元素代表一个硬币的面额，另给定一个总金额 `amount`，你需要用最少的硬币数来表示该金额。你可以认为每种面额的硬币有无穷多张。

#### 思路：

贪心算法的核心思想是每次选择当前能做出最优选择的硬币面额，直到金额被表示出来。对于此问题，可以先对硬币面额进行降序排列，然后从最大面额的硬币开始，逐步减小剩余金额，直到找出最少的硬币数量。

#### 代码：

```python
def coinChange(coins, amount):
    # 对硬币面额从大到小排序
    coins.sort(reverse=True)
    
    count = 0
    for coin in coins:
        # 用当前硬币尽可能多地凑出金额
        count += amount // coin  # 使用 coin 个硬币
        amount %= coin  # 更新剩余金额
    
    # 如果能将金额凑出来，返回硬币数，否则返回 -1
    return count if amount == 0 else -1

# 示例：硬币面额 [1, 2, 5] 组成 11
coins = [1, 2, 5]
amount = 11
print(coinChange(coins, amount))  # 输出 3 (5 + 5 + 1)
```

#### 解释：

1. **排序**：首先将硬币的面额从大到小排序，这样每次我们可以优先使用较大的硬币。
    
2. **贪心选择**：对于每种硬币面额，尽可能多地使用该面额的硬币，减少剩余金额。
    
3. **更新剩余金额**：通过 `amount // coin` 计算出最多能使用多少个当前面额的硬币，然后用 `amount %= coin` 更新剩余金额。
    
4. **检查是否能完全组成金额**：如果 `amount` 最终为 0，表示成功找到了最少的硬币数，否则返回 `-1` 表示无法凑出该金额。
    

### 2. **活动选择问题 (Activity Selection Problem)**

#### 题目：

给定 `n` 个活动，它们的开始时间和结束时间都已知。每个活动只能选一个，而且活动之间不能重叠，问最多能选择多少个活动。

#### 思路：

这是一个经典的贪心算法问题。我们可以选择结束时间最早的活动，因为选择结束时间最早的活动可以留出更多的时间来选择其他活动，从而获得更多的活动。

#### 代码：

```python
def activitySelection(start, end):
    n = len(start)
    activities = list(range(n))  # 活动的编号

    # 将活动按结束时间排序
    activities.sort(key=lambda x: end[x])

    count = 1  # 至少选择一个活动
    last_end_time = end[activities[0]]  # 第一个活动的结束时间

    # 从第二个活动开始选择
    for i in range(1, n):
        if start[activities[i]] >= last_end_time:  # 如果活动的开始时间 >= 上个选择活动的结束时间
            count += 1
            last_end_time = end[activities[i]]  # 更新结束时间
    
    return count

# 示例：活动的开始时间和结束时间
start = [1, 3, 0, 5, 8, 5]
end = [2, 4, 6, 7, 9, 9]
print(activitySelection(start, end))  # 输出 4
```

#### 解释：

1. **活动排序**：首先按结束时间对活动进行排序，确保我们每次选择结束时间最早的活动。
    
2. **贪心选择**：选择一个活动后，更新最后选择的活动的结束时间，然后选择下一个开始时间不早于这个结束时间的活动。
    
3. **结果**：返回可以选择的最大活动数量。
    

### 3. **任务调度问题 (Job Scheduling Problem)**

#### 题目：

给定一组任务，每个任务有一个开始时间、结束时间和奖励。任务之间不能重叠，问能选择的最大奖励是多少。

#### 思路：

此问题与活动选择问题相似，核心思想也是贪心选择结束时间最早的任务。在选择任务时，需要确保任务不重叠，且选择奖励最大化。

#### 代码：

```python
def jobScheduling(startTime, endTime, profit):
    jobs = sorted(zip(startTime, endTime, profit), key=lambda x: x[1])  # 按结束时间排序
    dp = [(0, 0)]  # (结束时间, 最大收益)

    for start, end, profit in jobs:
        # 找到结束时间 <= 当前任务开始时间的任务
        i = len(dp) - 1
        while i >= 0 and dp[i][0] > start:
            i -= 1
        # 如果可以选择该任务，更新最大收益
        if i >= 0:
            dp.append((end, max(dp[-1][1], dp[i][1] + profit)))
        else:
            dp.append((end, max(dp[-1][1], profit)))

    return dp[-1][1]

# 示例：任务的开始时间、结束时间和奖励
startTime = [1, 2, 3, 3]
endTime = [3, 5, 10, 6]
profit = [20, 20, 100, 70]
print(jobScheduling(startTime, endTime, profit))  # 输出 150
```

#### 解释：

1. **任务排序**：首先按结束时间对任务进行排序，这样我们可以从最早结束的任务开始选择。
    
2. **动态规划结合贪心选择**：用 `dp[i]` 来表示选择第 `i` 个任务时能够得到的最大奖励。每次考虑一个任务，找到所有可以选择的任务，然后更新最大奖励。
    
3. **结果**：返回最终的最大奖励。
    

### 4. **分割数组 (Split Array)**

#### 题目：

给定一个整数数组 `nums`，你需要将数组分成 `k` 个子数组，使得每个子数组的和的最大值最小。你可以用贪心算法来求解这个问题。

#### 思路：

此问题可以使用二分法和贪心算法结合的方法。我们通过二分查找来找到最小的最大和，然后用贪心算法来检查是否可以将数组分成 `k` 个子数组。

#### 代码：

```python
def splitArray(nums, k):
    def canSplit(nums, k, max_sum):
        count, current_sum = 1, 0  # 至少有一个子数组
        for num in nums:
            if current_sum + num > max_sum:
                count += 1
                current_sum = num
                if count > k:
                    return False
            else:
                current_sum += num
        return True

    left, right = max(nums), sum(nums)
    while left < right:
        mid = (left + right) // 2
        if canSplit(nums, k, mid):
            right = mid
        else:
            left = mid + 1

    return left

# 示例：数组 [7, 2, 5, 10, 8] 分成 2 个子数组
nums = [7, 2, 5, 10, 8]
k = 2
print(splitArray(nums, k))  # 输出 18
```

#### 解释：

1. **二分查找**：通过二分查找确定最小的最大和。搜索区间是 `max(nums)` 到 `sum(nums)`，即从最大元素到所有元素的和。
    
2. **贪心检查**：在每次二分时，使用贪心算法检查能否在最大和 `mid` 下，将数组分成 `k` 个子数组。
    
3. **结果**：返回最小的最大和。
