# MLP代码疑难解答

### 原代码 

```
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import DataLoader, TensorDataset

# 1. 准备数据 (生成一些简单的线性不可分的分类数据)
def create_dataset():
    # 生成 1000 个样本，每个样本 2 个特征
    X = torch.randn(1000, 2)
    # 目标逻辑：如果两个特征乘积为正则为类1，否则为类0 (类似 XOR 问题)
    y = ((X[:, 0] * X[:, 1]) > 0).float().unsqueeze(1)
    
    # 封装成 PyTorch 的数据集和加载器
    dataset = TensorDataset(X, y)
    return DataLoader(dataset, batch_size=32, shuffle=True)

# 2. 定义模型 (简单的多层感知机)
class SimpleNet(nn.Module):
    def __init__(self):
        super(SimpleNet, self).__init__()
        # 定义层结构
        self.layers = nn.Sequential(
            nn.Linear(2, 16),   # 输入层 (2) -> 隐藏层 (16)
            nn.ReLU(),          # 激活函数
            nn.Linear(16, 8),   # 隐藏层 (16) -> 隐藏层 (8)
            nn.ReLU(),
            nn.Linear(8, 1),    # 隐藏层 (8) -> 输出层 (1)
            nn.Sigmoid()        # 二分类输出映射到 0-1 之间
        )

    def forward(self, x):
        return self.layers(x)

# 3. MLP训练函数(大代码1)
def train():
    # 初始化
    model = SimpleNet()
    dataloader = create_dataset()
    
    # 定义损失函数 (二元交叉熵) 和 优化器 (Adam)
    criterion = nn.BCELoss()
    optimizer = optim.Adam(model.parameters(), lr=0.01)

    print("开始训练...")
    epochs = 20
    for epoch in range(epochs):
        total_loss = 0
        for batch_X, batch_y in dataloader:
            # 前向传播
            outputs = model(batch_X)
            loss = criterion(outputs, batch_y)
            
            # 反向传播与优化
            optimizer.zero_grad() # 清空梯度
            loss.backward()      # 计算梯度
            optimizer.step()     # 更新参数
            
            total_loss += loss.item()
        
        if (epoch + 1) % 5 == 0:
            print(f"轮次 [{epoch+1}/{epochs}], 平均损失: {total_loss/len(dataloader):.4f}")   # len=32，每轮次有32批次，所有的loss处以batch_size=每个batch有的loss，就是平均损失

    # 4. 简单评估
    print("\n训练完成，进行评估:")
    model.eval() # 切换到评估模式
    with torch.no_grad():
        test_X = torch.randn(100, 2)
        test_y = ((test_X[:, 0] * test_X[:, 1]) > 0).float().unsqueeze(1)
        predictions = model(test_X)
        predicted_classes = (predictions > 0.5).float()
        accuracy = (predicted_classes == test_y).float().mean()
        print(f"随机测试集准确率: {accuracy.item() * 100:.2f}%")

if __name__ == "__main__":
    train()
```



针对你提出的问题，这里对代码的核心逻辑进行了深度拆解。

### 1. `loss.backward()` 与 `y.backward()` 是一样的吗？

**结论：本质上完全一样。**

在 PyTorch 中，无论是一个简单的数学表达式还是复杂的神经网络，其自动求导（Autograd）机制是通用的。

- **简单代码中：** `y` 是一个根据变量 `x` 计算出来的标量。执行 `y.backward()` 时，PyTorch 会计算 $\frac{dy}{dx}$ 并存入 `x.grad` 中。
    
- **深度学习代码中：** `loss` 也是一个标量，它是根据模型的 `parameters`（权重 $W$ 和偏置 $b$）计算出来的。调用 `loss.backward()` 时，PyTorch 会计算损失函数对**所有**参数的偏导数，存入每个参数的 `.grad` 属性中。
    

### 2. `loss.item()` 是什么？

`loss` 在训练循环中通常是一个**仅包含一个元素的张量（Tensor）**。

- **作用：** 将单元素张量转换为普通的 **Python 浮点数**。
    
- **内存管理：** 这是为了切断计算图。如果直接累加 `loss` 张量，PyTorch 会为了以后的反向传播保留整个计算路径，导致显存迅速占满。
    

### 3. 代码片段详细解析

#### A. 数据准备阶段 (`create_dataset`)

这段代码是在“制造”老师给学生的练习题。

- `X = torch.randn(1000, 2)`：生成 1000 个题目，每个题目有 2 个数字（特征）。
    
- `y = ((X[:, 0] * X[:, 1]) > 0)...`：给每个题目定答案。逻辑是：如果两个数乘积大于 0，答案就是 1，否则是 0。
    
- `TensorDataset`：把题目 $X$ 和答案 $y$ 打包成一个“题库”。
    
- `DataLoader`：把“题库”变成“传送带”。`batch_size=32` 表示每次给模型看 32 道题；`shuffle=True` 表示每次看之前先打乱顺序，防止模型死记硬背。
    

#### B. 工具准备阶段 (`Criterion` & `Optimizer`)

- `criterion = nn.BCELoss()`：**判卷准则**。`BCELoss` (Binary Cross Entropy) 专门用于二分类问题，用来量化模型预测值与真实答案之间的差距。
    
- `optimizer = optim.Adam(...)`：**改错教练**。`Adam` 是一种非常聪明的算法，它决定了根据错误（梯度）如何调整模型的权重。`lr=0.01` 是学习率，决定了模型“步子”迈多大。
    

#### C. 前向传播 (`Forward Pass`)

- `outputs = model(batch_X)`：**模型做题**。把 32 道题喂给模型，模型给出它认为的答案。
    
- `loss = criterion(outputs, batch_y)`：**判卷**。对照标准答案 `batch_y`，计算出模型这次做得有多糟糕（loss 越小越好）。
    

### 4. 训练“三部曲”：必须每次都写吗？

**是的，在 PyTorch 中，这三行几乎是雷打不动的标准动作：**

```
optimizer.zero_grad() # 1. 橡皮擦：清空上一次累积的梯度
loss.backward()      # 2. 算错在哪：计算当前这一步所有参数的梯度
optimizer.step()     # 3. 改错：根据梯度更新权重参数

```

### 5. 进阶 Q&A (深度理解)

#### Q1: `batch_size=32` 是为了给 `model(batch_X)` 喂数据吗？

**是的。** `DataLoader` 的作用就是把 1000 个样本切成一小块一小块（Batch）。设置 `batch_size=32` 后，循环里的 `batch_X` 形状就是 `[32, 2]`。

- **为什么要分批？** 因为一次性把 100 万条数据塞进显卡会“爆显存”，而且分批训练（随机梯度下降）通常能让模型收敛得更好。
    

#### Q2: `outputs = model(batch_X)` 内部调用了 `forward` 吗？

**是的。** 在 PyTorch 中，当你像函数一样调用 `model(x)` 时，它会自动触发 `nn.Module` 内部的 `__call__` 方法，而 `__call__` 的核心任务就是去执行你定义的 `forward` 函数。

#### Q3: 为什么不每一轮次（Epoch）都打印 Loss？

在我们的示例代码中，我是为了让控制台**更简洁**（每 5 轮打印一次）。但在实际大型项目中，打印频率会更高。

#### Q4: 为什么要累加 Loss？它和“成本”的区别在哪？

这里涉及到一个严谨的数学定义和计算细节：

1. **计算逻辑**：
    
    - 在循环内，`total_loss += loss.item()` 确实是在计算**该轮次的总损失**。
        
    - 为了得到**平均成本**，我们在打印时执行了除法：`total_loss / len(dataloader)`（总损失除以总批次数）。
        
2. **“损失 (Loss)” vs “成本 (Cost)”**：
    
    - **损失 (Loss Function)**：通常指**单个样本**或**单个批次 (Batch)** 的误差。例如 `loss = criterion(outputs, batch_y)` 算的是这 32 个题的误差。
        
    - **成本 (Cost Function)**：通常指**整个数据集**上的平均误差。它是所有 Batch 损失的平均值。
        
    - **口语习惯**：在实际写代码时，大家经常混着叫，但严谨来说，`total_loss / N` 才是真正的“成本”。
        

#### Q5: 大型项目的结构和评估（Eval）逻辑是怎样的？

1. **训练脚本 (`train.py`)**：负责训练并保存权重（`.pth` 文件）。
    
2. **验证 (Validation)**：训练中途检查是否过拟合。
    
3. **测试 (Test)**：训练结束后，加载保存好的权重，在完全陌生的数据上评估。

### 7.  相关思考
1. **继承 `nn.Module`**：获得PyTorch神经网络的所有基础功能。比如向前传播，评估。
    
2. **`super().__init__()`**：确保父类正确初始化，只要有继承父类，就需要初始化命令。比如向前传播，评估。
    
3. **`nn.Linear`**：执行线性变换 `y = xW^T + b`
    
4. **`nn.ReLU`**：引入非线性，使神经网络能够学习复杂模式，深度学习需要非线性变换。将线性转化为非线性。
    
5. **`nn.Sigmoid`**：将输出转换为概率，适用于二分类问题，输出转化在（0,1）之间。

6.  **Softmax 做什么？**
    
    - 将任意数值转换为概率分布
        
    - 输出范围：[0, 1]，总和为 1


| 特性       | **nn.Softmax** | **nn.Sigmoid**     |
| -------- | -------------- | ------------------ |
| **输出总和** | **所有输出之和为 1**  | **每个输出独立，和不一定为 1** |
| **应用场景** | 多分类（互斥类别）      | 二分类、多标签分类          |
| **数学性质** | 相互依赖的归一化       | 独立的非线性变换           |
| **输出数量** | K 个输出的概率分布     | 每个输出独立在 [0,1]      |




# CNN代码样例解析

```

import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import Dataset, DataLoader
import random

# ==========================================
# 1. 高级数据准备 (模拟图像数据)
# ==========================================
# 在真实项目中，这里通常是读取图片文件。
# 为了让代码自包含，我们自定义一个 Dataset 类来实时生成 "假图片"。
# 任务：识别图片里画的是 "横线"、"竖线" 还是 "十字"。
class ShapeDataset(Dataset):
    def __init__(self, num_samples=1000):
        self.num_samples = num_samples
        self.img_size = 28  # 模拟 28x28 像素的图片

    def __len__(self):
        return self.num_samples

    def __getitem__(self, idx):
        # 初始化一张全黑的图片 (单通道, 28x28)
        # 形状必须是 [C, H, W]，即 [通道数, 高, 宽]
        img = torch.zeros(1, self.img_size, self.img_size)
        
        # 随机决定生成哪个类别：0=横线, 1=竖线, 2=十字
        label = random.randint(0, 2)
        
        # 添加一些随机噪声 (模拟真实世界的干扰)
        noise = torch.randn(1, self.img_size, self.img_size) * 0.2
        img += noise

        # 根据标签画图 (将对应像素点设为高亮 1.0)
        c = self.img_size // 2
        if label == 0: # 画横线
            img[:, c-2:c+2, :] = 1.0 
        elif label == 1: # 画竖线
            img[:, :, c-2:c+2] = 1.0
        elif label == 2: # 画十字
            img[:, c-2:c+2, :] = 1.0
            img[:, :, c-2:c+2] = 1.0
            
        return img, label

# ==========================================
# 2. 定义卷积神经网络 (CNN)
# ==========================================
class ConvNet(nn.Module):
    def __init__(self):
        super(ConvNet, self).__init__()
        
        # 特征提取层 (Feature Extractor)
        # 作用：像眼睛一样，从图片中提取线条、边缘等特征
        self.features = nn.Sequential(
            # 卷积层 1: 输入1通道(黑白), 输出16通道(特征图), 卷积核3x3
            nn.Conv2d(in_channels=1, out_channels=16, kernel_size=3, padding=1),
            nn.ReLU(),              # 激活函数
            nn.MaxPool2d(2, 2),     # 池化层: 图片尺寸减半 (28->14)，保留最明显的特征

            # 卷积层 2: 输入16通道, 输出32通道
            nn.Conv2d(16, 32, 3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2, 2)      # 图片尺寸再减半 (14->7)
        )
        
        # 分类层 (Classifier)
        # 作用：根据提取出的特征，进行逻辑判断
        self.classifier = nn.Sequential(
            nn.Flatten(),           # 展平: 将多维特征图 [32, 7, 7] 变成一维向量 [32*7*7] = [1568]
            nn.Linear(32 * 7 * 7, 128), # 全连接层
            nn.ReLU(),
            nn.Dropout(0.5),        # Dropout: 随机丢弃 50% 的神经元，防止死记硬背 (过拟合)
            nn.Linear(128, 3)       # 输出层: 输出 3 个类别的得分
        )

    def forward(self, x):
        x = self.features(x)
        x = self.classifier(x)
        return x

# ==========================================
# 3. 训练与验证流程
# ==========================================
def train_and_evaluate():
    # --- 配置 ---
    device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
    print(f"使用设备: {device}")
    
    BATCH_SIZE = 64
    LEARNING_RATE = 0.001
    EPOCHS = 10

    # --- 数据加载 ---
    train_data = ShapeDataset(num_samples=2000)
    test_data = ShapeDataset(num_samples=500)
    
    train_loader = DataLoader(train_data, batch_size=BATCH_SIZE, shuffle=True)
    test_loader = DataLoader(test_data, batch_size=BATCH_SIZE, shuffle=False)

    # --- 模型初始化 ---
    model = ConvNet().to(device)
    
    # 损失函数: CrossEntropyLoss 用于多分类
    # 注意: 它内部自动包含了 Softmax，所以模型输出不需要加 Softmax
    criterion = nn.CrossEntropyLoss()
    
    # 优化器: Adam
    optimizer = optim.Adam(model.parameters(), lr=LEARNING_RATE)

    # --- 训练循环 ---
    print("\n>>> 开始训练 CNN 模型...")
    for epoch in range(EPOCHS):
        model.train() # 开启训练模式 (启用 Dropout)
        running_loss = 0.0
        
        for images, labels in train_loader:
            images, labels = images.to(device), labels.to(device)
            
            # 标准三部曲
            optimizer.zero_grad()           # 1. 清空梯度
            outputs = model(images)         # 2. 前向传播
            loss = criterion(outputs, labels) # 3. 计算损失
            loss.backward()                 # 4. 反向传播
            optimizer.step()                # 5. 更新参数
            
            running_loss += loss.item()

        # --- 每个 Epoch 结束后进行测试 ---
        model.eval() # 开启评估模式 (关闭 Dropout)
        correct = 0
        total = 0
        with torch.no_grad(): # 评估时不计算梯度，节省内存
            for images, labels in test_loader:
                images, labels = images.to(device), labels.to(device)
                outputs = model(images)
                
                # torch.max 返回 (最大值, 索引)，我们要的是索引(类别)
                _, predicted = torch.max(outputs.data, 1)
                total += labels.size(0)
                correct += (predicted == labels).sum().item()

        avg_loss = running_loss / len(train_loader)
        acc = 100 * correct / total
        print(f"Epoch [{epoch+1}/{EPOCHS}] | Loss: {avg_loss:.4f} | Test Accuracy: {acc:.2f}%")

    # --- 最终演示预测 ---
    print("\n>>> 最终演示 (随机抽取一张测试图):")
    model.eval()
    sample_img, sample_label = test_data[0] # 拿一张图
    # 增加 batch 维度: [1, 28, 28] -> [1, 1, 28, 28]
    input_tensor = sample_img.unsqueeze(0).to(device) 
    
    with torch.no_grad():
        output = model(input_tensor)
        probabilities = torch.nn.functional.softmax(output, dim=1)
        predicted_class = torch.argmax(probabilities).item()
    
    class_names = ["横线 (-)", "竖线 (|)", "十字 (+)"]
    print(f"真实标签: {class_names[sample_label]}")
    print(f"模型预测: {class_names[predicted_class]}")
    print(f"各类别置信度: {probabilities[0].cpu().numpy()}")

if __name__ == "__main__":
    train_and_evaluate()
```


## 问题与思考：


### Q1: 这些项目都没有用到 Attention 吧？Attention 里面会用到卷积层或者 LSTM 吗？

**1. 现状确认**

是的，目前的三个项目（MLP, CNN, LSTM）都是**经典的基础架构**，完全**没有**使用 Attention（注意力机制）。

- **MLP**: 全连接，暴力计算。
    
- **CNN**: 局部感知，像眼睛扫描图片。
    
- **LSTM**: 序列记忆，像人读句子记住上下文。
    

**2. Attention 与 CNN/LSTM 的关系**

Attention 是一种机制，它既可以“独立门户”，也可以和 CNN/LSTM “合作”。

- **合作模式 (Hybrid)**：
    
    - **CNN + Attention**: 常用在图像任务中。例如，CNN 负责看图，Attention 负责告诉模型“现在该看图片的哪个角落”。（比如生成图片描述时，说到“鸟”的时候，Attention 机制会让模型聚焦在图片中鸟的像素上）。
        
    - **LSTM + Attention**: 早期机器翻译（Seq2Seq）的标配。LSTM 负责读句子，Attention 负责在翻译每个词时，回头看原句中相关的词。
        
- **替代模式 (Transformer)**：
    
    - 现在最火的 **Transformer** 架构（如 ChatGPT, BERT）就是**纯 Attention**，完全抛弃了 LSTM。
        
    - 在图像领域，**Vision Transformer (ViT)** 甚至开始尝试抛弃 CNN，直接用 Attention 处理图像块。
        

**结论**：Attention 是一种“思想”（聚焦重点），它可以加在 CNN/LSTM 上增强能力，也可以自立门户（Transformer）取代它们。

### Q2: `optimizer = optim.Adam(...)` 这句里的 Adam 是什么意思？`lr` 是会逐渐下降吗？

#### 1. Adam 是什么？

`Adam` (Adaptive Moment Estimation) 是目前深度学习中最流行的**优化器**（教练）。

- **传统 SGD (随机梯度下降)**：不管地形如何，每一步都走固定的长度（由学习率决定）。容易在平坦的地方走得慢，在陡峭的地方走过头。
    
- **Adam (自适应)**：它非常聪明，会为**每一个参数**单独维护一个学习率。
    
    - 如果某个参数过去的梯度很大，Adam 会让它步子迈小点，防止震荡。
        
    - 如果某个参数梯度很稀疏或很小，Adam 会让它步子迈大点，加速收敛。
        
    - **类比**：SGD 是蒙眼下山，Adam 是带了导航和路况分析的智能下山。
        

#### 2. `lr=LEARNING_RATE` 是逐渐下降的吗？

**在当前这行代码中：不是。**

```
optimizer = optim.Adam(model.parameters(), lr=0.001)
```

- **含义**：这设置的是**初始**全局学习率 (Initial Global Learning Rate)。
    
- **行为**：如果你只写这一行，不加额外代码，这个 `0.001` 在训练的第 1 轮是 `0.001`，在第 1000 轮依然是 `0.001`。它**不会**自动下降。
    

#### 3. 如何实现“逐渐下降” (Learning Rate Decay)？

虽然 Adam 内部会微调，但通常我们还是希望全局学习率随着训练进行越来越小（以此来精细调整模型，好比穿针引线时手要稳）。

要实现这个，需要引入 **Scheduler (调度器)**。

**代码示例 (如何修改以支持下降)：**

```
# 1. 定义优化器 (lr 初始为 0.001)
optimizer = optim.Adam(model.parameters(), lr=0.001)

# 2. 定义调度器 (每隔 5 轮，把 lr 乘以 0.1)
# 也就是：前5轮 0.001 -> 后5轮 0.0001 -> ...
scheduler = torch.optim.lr_scheduler.StepLR(optimizer, step_size=5, gamma=0.1)

# 3. 在训练循环中更新
for epoch in range(EPOCHS):
    train(...)
    validate(...)
    scheduler.step() # <--- 这里触发生效
```

### 总结

1. **Attention** 是进阶机制，现在的代码还没用到。它既可以辅助 CNN/LSTM，也可以取代它们（Transformer）。
    
2. **Adam** 是一个自带“路况适应”功能的智能优化器。
    
3. **`lr=...`** 只是设定初始值，要想让它随时间下降，需要显式添加 `scheduler.step()`。




### 1. 关于 Optimizer 和 Scheduler

**你的误解：** `Adam` 并不只能做“微调”。

事实上，`Adam`（Adaptive Moment Estimation）是目前深度学习中最主流、最全能的优化器之一。它通过为每个参数维护自适应学习率，在训练初期能快速收敛。

**为什么这里没用 Scheduler？**

- **复杂度较低：** 对于简单的分类任务（如你代码中的形状识别），固定的学习率（如 0.001）通常足以在 10 个 Epoch 内降到理想损失。
    
- **Adam 自带调节：** Adam 内部已经有动量和自适应机制，对初始学习率不那么敏感。
    
- **进阶做法：** 在大型项目（如跑 MAE 或 DINOv2）中，确实需要 `StepLR` 或 `CosineAnnealingLR` 来在训练后期压低学习率，以寻找全局最优解。

### 3. 如何添加 Checkpoint（模型存档）

代码没有写保留 Checkpoint 是因为这只是个演示脚本。但在实际开发中，**不存模型等于白练**。

如果要加上去，你需要在训练循环中通过 `torch.save` 保存状态字典（`state_dict`）。

#### 建议增加的函数：

Python

```
def save_checkpoint(model, optimizer, epoch, path="checkpoint.pth"):
    checkpoint = {
        'epoch': epoch,
        'model_state_dict': model.state_dict(),
        'optimizer_state_dict': optimizer.state_dict(),
    }
    torch.save(checkpoint, path)
    print(f"Checkpoint saved at epoch {epoch+1}")
```

#### 在代码中的放置位置：

通常我们会判断：如果当前 Epoch 的 `Test Accuracy` 是历史最高的，就保存一份 `best_model.pth`。

Python

```
best_acc = 0.0
# ... 在训练循环中 ...
if acc > best_acc:
    best_acc = acc
    save_checkpoint(model, optimizer, epoch, "best_model.pth")
```

import torch

import torch.nn as nn

import torch.optim as optim

import numpy as np


# ==========================================

# 1. 制造数据：模拟正弦波 (Sine Wave)

# ==========================================

# 任务：根据过去的 50 个点，预测下一个点的值

def create_dataset(seq_length=50, num_samples=1000):

    # 生成时间轴 x

    x = np.linspace(0, 100, num_samples + seq_length + 1)

    # 生成正弦波数据 y = sin(x)

    y = np.sin(x)

    X_data, y_data = [], []

    for i in range(num_samples):

        # 取一段长度为 seq_length 的序列作为输入

        seq = y[i : i+seq_length]

        # 取紧接着的一个点作为预测目标

        target = y[i+seq_length]

        X_data.append(seq)

        y_data.append(target)

    # 转换为 Tensor，形状说明：

    # Input: [Batch, Sequence_Length, Input_Size]

    # 对于简单的单变量时间序列，Input_Size = 1

    return torch.tensor(np.array(X_data), dtype=torch.float32).unsqueeze(-1), \

           torch.tensor(np.array(y_data), dtype=torch.float32).unsqueeze(-1)

  

# ==========================================

# 2. 定义 LSTM 模型

# ==========================================

class SimpleLSTM(nn.Module):

    def __init__(self):

        super(SimpleLSTM, self).__init__()

        # LSTM 层

        # input_size=1 (因为我们只看正弦波这一个值)

        # hidden_size=32 (记忆单元的大小，越大越能记复杂模式)

        # num_layers=1 (层数)

        # batch_first=True (让输入数据的第一个维度是 batch_size)

        self.lstm = nn.LSTM(input_size=1, hidden_size=32, num_layers=1, batch_first=True)

        # 全连接层：把 LSTM 的记忆转换成最终的预测值

        self.linear = nn.Linear(32, 1)

  

    def forward(self, x):

        # lstm_out 包含所有时间步的输出

        # _ (hidden_state) 包含最后的记忆状态 (这里暂时不用)

        lstm_out, _ = self.lstm(x)

        # 我们只关心最后一个时间步的输出 (last_time_step)

        # 形状变化: [Batch, Seq_Len, Hidden] -> [Batch, Hidden]

        last_time_step = lstm_out[:, -1, :]

        # 预测

        prediction = self.linear(last_time_step)

        return prediction

  

# ==========================================

# 3. 训练流程

# ==========================================

def train_forecast():

    # 准备数据

    seq_length = 50

    X, y = create_dataset(seq_length)

    # 定义模型、损失函数和优化器

    model = SimpleLSTM()

    criterion = nn.MSELoss() # 回归问题常用均方误差 (Mean Squared Error)

    optimizer = optim.Adam(model.parameters(), lr=0.01)

    print(">>> 开始训练 LSTM 预测正弦波...")

    # 训练 100 轮

    for epoch in range(100):

        optimizer.zero_grad()

        outputs = model(X)

        loss = criterion(outputs, y)

        loss.backward()

        optimizer.step()

        if (epoch+1) % 10 == 0:

            print(f"Epoch [{epoch+1}/100], Loss: {loss.item():.6f}")

  

    # ==========================================

    # 4. 验证效果 (让模型自己跑一段)

    # ==========================================

    print("\n>>> 验证预测效果:")

    model.eval()

    # 拿第一条数据作为"种子"

    test_seq = X[0].unsqueeze(0) # [1, 50, 1]

    predicted_values = []

    # 连续预测未来 10 个点

    with torch.no_grad():

        for _ in range(10):

            # 预测下一步

            pred = model(test_seq)

            predicted_values.append(pred.item())

            # 这里的逻辑很关键：自回归 (Auto-Regressive)

            # 把预测出来的新值加到序列末尾，扔掉最旧的一个值

            # 形成新的输入，去预测再下一个点

            new_val = pred.unsqueeze(1) # [1, 1, 1]

            test_seq = torch.cat((test_seq[:, 1:, :], new_val), dim=1)

    print("真实规律 (约): [0.0, 0.08, 0.16, ... 正弦波上升]")

    print(f"模型预测: {[round(v, 2) for v in predicted_values]}")

    # 简单的文本可视化

    print("\n可视化对比 (First 5 predictions):")

    for i, val in enumerate(predicted_values[:5]):

        bar = "#" * int((val + 1) * 10) # 简单的 ASCII 条形图

        print(f"Step {i+1}: {val:.2f} | {bar}")

  

if __name__ == "__main__":

    train_forecast()
