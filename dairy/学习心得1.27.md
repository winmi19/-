**创建python虚拟环境**：
```
python -m venv venv
```

或者指定版本：
```
python3.8 -m venv venv
```


**激活**：
```
source venv/bin/activate
```


# 部署docker

首先拉取镜像，确保能run 

```
docker pull docker.1ms.run/nvidia/cuda:12.6.0-devel-ubuntu22.04 #举个例子
```

**注意**：如果拉取不到，就去docker.1ms.run里面找

接着docker run 跑的是容器
```
docker run -it --name dm_sensor_env --gpus all --privileged --net=host -e DISPLAY=$DISPLAY -v /tmp/.X11-unix:/tmp/.X11-unix -v "/home/shuangmulin/DWM_datacollect/DM-Tac W/Daimon-Tactile-Publish 20250909:/workspace/sdk" --device=/dev/video2:/dev/video2 --device=/dev/video3:/dev/video3 --device=/dev/video4:/dev/video4 --device=/dev/video5:/dev/video5 --device=/dev/video6:/dev/video6 --device=/dev/video7:/dev/video7 docker.1ms.run/nvidia/cuda:12.6.0-devel-ubuntu22.04 bash
```

如果没启动
```
docker start dm_sensor_env
```

然后进入容器
```
docker exec -it dm_sensor_env bash
```

如果要退出
```
exit
```

查看所有容器
```
docker ps -a   #-a即查看所有，包括已经停止了的
```

# 什么是张量 (Tensor)？——AI世界的通用货币

在学习人工智能代码时，你最先遇到的概念一定是 **Tensor（张量）**。

不用被这个物理学术语吓跑，在 AI 编程里，它其实就是一个 **“超级容器”**。

我们可以把张量看作是**数据的容器**，根据容器的形状不同，它们有不同的名字：

## 1. 维度的阶梯：从点到体

我们可以用“超市理货”来类比张量的不同形态：

### 0阶张量 (Scalar / 标量) —— 一个数

- **形态**：一个单独的苹果。
    
- **例子**：`loss = 0.4` (你的模型现在的误差值)。
    
- **代码**：`torch.tensor(0.4)`
    

### 1阶张量 (Vector / 向量) —— 一排数

- **形态**：一列货架，上面摆了一排苹果。
    
- **例子**：`[0.1, 0.4, 0.5]` (一张图片属于猫、狗、鸟的概率)。
    
- **代码**：`torch.tensor([0.1, 0.4, 0.5])`
    

### 2阶张量 (Matrix / 矩阵) —— 一个面

- **形态**：整面墙的货架，好几排苹果。这就像 Excel 表格。
    
- **例子**：一张黑白照片（高 x 宽，每个格子里是像素亮度）。
    
- **代码**：`torch.tensor([[0.1, 0.2], [0.3, 0.4]])`
    

### 3阶及更高阶张量 (Tensor / 张量) —— 一个体

- **形态**：整个仓库的货架（有长、宽、高）。
    
- **例子**：
    
    - **3阶**：一张**彩色照片** (高度 x 宽度 x 3个颜色通道RGB)。
        
    - **4阶**：**一批彩色照片** (批次大小Batch x 通道 x 高 x 宽)。这在你的配置文件里就是 `Batch Size` 的概念。
        
    - **5阶**：**一段视频** (批次 x 时间帧 x 通道 x 高 x 宽)。
        

## 2. 为什么人工智能非用张量不可？

为什么不直接用 Python 的列表 (List) 或者普通的数字呢？

### 原因一：现实世界的数据本来就是高维的

AI 要处理的数据通常都很复杂：

- **图片**是 3D 的（高、宽、颜色）。
    
- **视频**是 4D 的（时间、高、宽、颜色）。
    
- **语言**处理时，一个句子可能被表示为（单词数 x 词向量维度）。
    
    只有张量这种“任意维度”的容器，才能把这些复杂数据统一装下来。
    

### 原因二：为了“批发”计算 (并行计算)

这是最重要的原因。

- **不用张量**：就像老师改卷子，一张一张改。如果你有 1000 张图要处理，用普通的 `for` 循环一张张算，速度会慢死。
    
- **使用张量**：张量允许我们把 1000 张图打包成一个 4阶张量 `[1000, 3, 224, 224]`。
    
    - 显卡 (GPU) 最擅长的就是 **“并发处理”**。它看到张量，就会同时对这 1000 张图做完全一样的数学运算。
        
    - 这就好比工厂流水线，一次性给 1000 个瓶子盖盖子，而不是一个人扭完一个再扭下一个。
        

### 原因三：自动求导 (Automatic Differentiation)

在 AI 框架（如 PyTorch）里的张量，不仅仅存数据，它还**自带“记忆”**。

- 当你用张量做计算（加减乘除）时，张量会在后台默默记下：“我是被谁加出来的？我又被乘了多少？”
    
- 当你需要优化模型时，程序可以顺着这些“记忆”往回倒推，算出每个参数该怎么修改（这就是反向传播）。普通的 Python 数字是没有这种记忆功能的。
    

## 3. 总结

- **张量 (Tensor)** 就是一个多维数组。
    
- 它是 AI 里的**标准数据格式**。
    
- 无论是声音、图像、文字还是视频，进入 AI 模型前，**统统都要被打碎变成张量**。
