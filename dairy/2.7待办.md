### 中国高校智能机器人创意大赛
#### 一、 大赛简介：这是个什么比赛？

**中国高校智能机器人创意大赛**（China University Intelligent Robot Creative Competition）是由中国高等教育学会、教育部工程图学课程教学指导委员会等单位主办的高级别学科竞赛。

- **核心地位**：该赛事已被列入全国普通高校大学生竞赛排行榜（俗称“A类赛事”），在保研、评奖评优中认可度极高。
  

#### 二、 赛项设置（划重点：你要报哪个？）

大赛主要分为**主题赛**、**专项赛**和**产教融合赛**。对于第一次参赛的团队，通常建议从**主题赛**入手。

智能拐杖机器人

##### 专项赛与产教融合赛

包括**俄罗斯方块机器人**、**具身智能挑战赛**（四足/双足）、**VEX U**以及**信捷电气**、**百度**等企业命题赛道。如果你所在的实验室刚好有相关设备（如四足狗）或企业资源，可以考虑。

## 全球校园**人工智能算法**精英**大赛**

**算法应用赛智慧社区赛道**：(即应用赛道)

以 **无人车视觉巡航赛**为例子


### 一、 核心知识技能图谱（融会贯通）

在开始之前，理解各项技术是如何“串联”起来的至关重要：

1. **数字电路/单片机**：负责最底层的电机驱动、电量监测和传感器原始数据读取。
    
2. **传感器技术**：激光雷达（测距/避障）、摄像头（巡航/识别）、IMU（姿态感知）。
    
3. **C++/Python & ROS**：作为“神经中枢”，连接底层驱动与高层算法，实现数据分发。
    
4. **计算机视觉/深度学习**：负责从摄像头画面中提取车道线、交通标志、障碍物。
    
5. **自动控制**：根据视觉输出，通过 PID 或模型预测控制（MPC）计算电机的精准转速。
    
6. **激光 SLAM**：在复杂赛道中进行定位与建图（如果涉及自主导航）。
    

### 二、 硬件选型与配件购买

#### 1. 计算平台（大脑）

- **推荐**：Jetson Nano B01 或 Jetson Orin Nano（具备 GPU 算力，适合深度学习）。
    
- **备选**：树莓派 4B/5（适合纯 OpenCV 图像处理，深度学习较吃力）。
    

#### 2. 车体底盘（躯干）

- **类型**：阿克曼转向（类似真车，控制复杂但稳定）或 差速转向（易于原地旋转，机动性强）。
    
- **电机**：带编码器的直流减速电机（必须带编码器以获取里程计数据）。
    

#### 3. 传感器（感官）

- **视觉**：USB 广角摄像头或 CSI 摄像头（索尼 IMX219 传感器）。
    
- **避障**：思岚 A1/A2 激光雷达。
    
- **姿态**：MPU6050 或更高精度的 IMU。
    

#### 4. 电源系统（血液）

- **电池**：12V 锂电池组（注意容量与放电倍率）。
    
- **降压模块**：将 12V 稳定降压至 5V 给主板供电。
    

### 三、 硬件搭建步骤

1. **底盘组装**：安装电机、轮子及避障支架。
    
2. **电路连接**：
    
    - 单片机（如 STM32/ESP32）作为下位机，连接电机驱动板（如 L298N 或 TB6612）。
        
    - 计算平台（如 Jetson）作为上位机，通过串口与下位机通信。
        
3. **结构加固**：使用扎带或 3D 打印件固定线缆，确保摄像头安装角度固定且视野无遮挡。
    

### 四、 软件架构与算法编写

#### 第一阶段：底层驱动（C++/C）

- **任务**：编写单片机程序。
    
- **功能**：接收上位机下发的转速指令，通过 **PID 算法**控制电机达到目标速度，并返回编码器数据。
    

#### 第二阶段：视觉巡航算法（Python/C++ + OpenCV）

- **传统图像处理流**：
    
    1. **预处理**：灰度化、高斯滤波、ROI（感兴趣区域）截取。
        
    2. **特征提取**：Canny 边缘检测或颜色空间阈值分割（如 HSV 过滤黄色车道线）。
        
    3. **透视变换**：将画面转为“鸟瞰图”，消除远小近大的影响。
        
    4. **中心线提取**：计算左右车道线的中心点，得出偏离距离（Error）。
        
- **深度学习流（进阶）**：
    
    - 使用深度学习模型（如 MobileNet-SSD 或 YOLO-Pose）识别特定交通标识或行人。
        



#### 第三阶段：决策与控制

- **ROS (Robot Operating System)**：
    
    - 使用 `cv_bridge` 将摄像头图像转为 ROS 消息。
        
    - 编写一个 `control_node`：根据视觉提取的 `Error`（偏离量），计算出 `Angular Velocity`（角速度）。
        
    - **控制逻辑**：`速度 = 基础速度 - k * |偏离量|`，实现弯道减速。
        


### 五、 调试技巧

1. **离线调试**：先录制赛道视频，在电脑上调整 OpenCV 参数（如阈值），避免频繁跑车。
    
2. **PID 参数整定**：
    
    - 先调 `P`（比例）：让车能跟上线，但会有振荡。
        
    - 后调 `D`（微分）：抑制过冲，让转向更平滑。
        
3. **光照鲁棒性**：赛场灯光可能与实验室不同。务必在算法中加入自动曝光调整或使用更稳定的色彩空间（如 HSL/LAB）。
    


### 六、 融会贯通的建议

- **模块化开发**：不要把所有代码写在一个文件里。视觉模块、驱动模块、控制模块应通过标准接口（如 ROS Topic）通信。
    
- **多版本备份**：在调试出可以稳定跑完一圈的代码后，立即备份。不要在比赛前一刻做大幅度修改。
    
- **仿真优先**：如果条件允许，可以使用 Gazebo 或 Webots 搭建虚拟赛道进行算法验证，节省硬件损耗。

## 睿抗机器人大赛

### 工程竞技赛道：
|赛道类别|核心侧重点|关键特性与技术难点|
|---|---|---|
|**农业类 (如: 智慧果园/智灌)**|**精细化识别与柔性操作**|需区分果实成熟度（全熟/半熟/坏果），对视觉模型精细度要求极高。采摘需“手眼配合”，防止误伤植物。|
|**人形专项 (如: 硕博精英赛)**|**步态稳定与复杂协同**|侧重于人形机器人的动态平衡。相对于轮式，人形底盘在移动时相机抖动大，对视觉算法的鲁棒性有更高要求。|
|**大模型融合类 (如: 无人机)**|**语义理解与跨模态调度**|重点在于如何将大模型生成的“抽象计划”转化为无人机或机器人的“具体动作序列”，侧重于逻辑决策层。|
|**工业类 (如: 螺丝装配)**|**高精度定位与力量控制**|螺丝孔位极小，对机械臂的重复定位精度和末端力控要求极高，容错率低于农业采摘。|
|**巡检与侦察 (如: 四足巡检)**|**环境适应与多传感器融合**|四足机器人需面对非平整地面，侧重于避障算法、地形适应能力以及多模态数据（视觉/红外等）的实时回传。|
|**竞技类 (如: 足球/夺宝)**|**实时性与对抗策略**|环境是动态变化的。侧重于算法的低延迟响应、动态目标跟踪以及在竞争环境下的路径博弈。|
|**零售/物流类 (如: 智慧零售)**|**空间效率与订单处理逻辑**|侧重于多目标的最优路径规划（如何最快搬完所有货物）和对多样化包装货物的抓取稳定性。|




#### 人形虚拟仿真赛项

**定位**：侧重于软件控制、视觉感知与路径规划，是纯算法能力的博弈。

- **比赛形式**：
    
    - **环境**：基于 **ROS2 Humble** 系统和 **Webots** 仿真软件。
        
    - **流程**：模拟家庭环境。机器人需要听懂语音指令，在复杂户型中自主导航，识别特定的物品（如水杯），完成精细的抓取动作，并避开固定或动态障碍物。
        
- **产品落地要求**：
    
    - **多模态交互**：语音指令解析 -> 视觉识别 -> 动作执行。这要求算法具备极高的鲁棒性，不能只是“写死路径”。
        
    - **精细操作**：仿真环境中对抓取力度、放置位置（是否直立）有严格扣分项，模拟现实中人形机器人处理家务的细腻度。
        
- **侧重点**：**ROS2开发功底**。如果你擅长SLAM（建图导航）、MoveIt（机械臂控制）以及视觉分类，这个赛道最适合。
    

#### 人形比选赛项

**定位**：侧重于场景定义、商业逻辑与方案集成，是“产品经理”视角。

- **比赛形式**：
    
    - **载体**：方案申报书 + 现场演示/答辩。
        
    - **核心内容**：不仅要设计机器人，更要论证它的“钱景”。需要填写包括：应用场景痛点分析、技术路线、**商业模式（盈利方式）**、**经济效益分析**以及产业联动效应。
        
- **产品落地要求**：
    
    - **实用性**：你的方案必须解决具体问题（如养老陪护中的起身辅助、工业制造中的精密装配）。
        
    - **落地可行性**：不能只讲科幻，要分析现有的技术能否支撑该成本下的规模化推广。
        
- **侧重点**：**产学研结合**。适合有成熟项目 demo、专利储备，且希望将科研成果向初创产品转化的团队。
    

#### 人形安全赛项

**定位**：侧重于网络安全、系统加固与攻防对抗，是目前人形机器人领域最前沿的冷门赛道。

- **比赛形式**：
    
    - **省赛（线上）**：CTF（夺旗赛）+ 知识赛。考察网络安全基础和机器人特有协议安全。
        
    - **国赛（线下）**：**自由漏洞挖掘**。在实物人形机器人上找 Bug。范围包括通信协议漏洞、硬件接口漏洞、操作系统漏洞等。
        
- **产品落地要求**：
    
    - **安全认证**：人形机器人未来进入家庭或工厂，安全是第一准则。该赛项要求选手具备“黑客思维”，先攻后防。
        
    - **漏洞修复**：挖掘出漏洞后，需提交漏洞报告（CVSS 评分），并给出加固方案。
        
- **侧重点**：**渗透测试能力**。适合计算机网络安全背景、熟悉嵌入式系统安全（如 Linux 内核安全、Wi-Fi/蓝牙通信协议破解）的团队。


#### 4. 物流小车赛项：移动的“调度员”

**定位**：属于**智能物流与零售类**。侧重于多目标的最优路径规划与复杂地形适应。

- **比赛形式**：
    
    - **运输对抗组**：红蓝对抗，在 3 分钟内自主收集圆环。考点在于博弈策略（如何先达成“完胜”条件）与高频次的抓取/堆叠。
        
    - **智能补给挑战组**：全流程自动化，包括取料、过战壕、加工、装配、质检、入库。环境复杂（含斜坡、深坑）。
        
- **产品落地要求**：
    
    - **高效率调度**：在“智能补给”组中，机器人需根据信号牌状态实时切换任务，模拟智能工厂的柔性生产流程。
        
    - **跨越能力**：物理结构需兼顾轻量化与越障能力（战壕穿越）。
        
- **侧重点**：**系统性工程思维**。需平衡底盘稳定性与执行器灵活性，优化多任务的优先级逻辑。
    

#### 5. 智慧零售赛项：终端的“分拣师”

**定位**：属于**智能物流与零售类**。侧重于空间效率、视觉抓取精度与环境感知。

- **比赛形式**：
    
    - **环境**：模拟新零售仓库，包含公共货架、充能站、仓库货架。
        
    - **任务**：手动/自主混合模式。核心难点在于**视觉识别抓取**（识别积木块上的特定图案，如猫、狗、钟表等）并进行精准分类放置。
        
- **产品落地要求**：
    
    - **视觉识别深度**：要求机器人不仅能识别“物块”，还要能区分细微的贴纸图案差异，对应零售场景中SKU极度丰富的特征。
        
    - **成本控制**：规则对雷达和相机价格有限制，考察选手在有限成本下实现高精度定位的能力。
        
- **侧重点**：**视觉识别与抓取稳定性**。适合擅长轻量化视觉模型开发及机械臂末端控制的团队。


#### 平安城市赛项：全能的“警务通”

**定位**：属于**综合类**。它是所有赛项中“任务清单”最长的项目，极其考验多任务并行处理能力。

- **比赛形式**：
    
    - **环境**：模拟城市场景，包含双边桥、S弯、红绿灯、垃圾桶、楼宇等。
        
    - **任务**：机器人需要完成“巡、识、取、送”闭环。包括抓取货架物资、准确投递、识别四个点的人群数量、识别楼宇信息、判断红绿灯状态（需等待绿色）、识别垃圾桶并判断投放情况。
        
- **产品落地要求**：
    
    - **多目标识别能力**：机器人要在运动中准确切换识别模型（识人 -> 识字 -> 识颜色 -> 识垃圾）。
        
    - **逻辑决策鲁棒性**：例如红绿灯逻辑，一旦判断错误（闯红灯）会有严重处罚。
        
- **侧重点**：**视觉识别与逻辑编排**。这个项目对硬件底盘要求适中，但对软件层面的任务状态机（FSM）设计要求非常高。
    

#### 7. 四足多模态巡检赛项：灵活的“侦察兵”

**定位**：属于**巡检与侦察类**。它是最依赖机体机动性的赛项，重点在于“全地形行走”。

- **比赛形式**：
    
    - **环境**：包含障碍物、台阶（楼梯）、避障区等。
        
    - **任务**：四足机器人（如宇树 Go2）需要自主跨越台阶，运送特定形状的物资（球、长方体、棱锥等）到指定平台。
        
- **产品落地要求**：
    
    - **地形感知与通过性**：四足机器人的优势在于上下楼梯，这要求选手能够调用深度相机进行地形重构，确保机器人步态在斜坡和台阶上不摔倒。
        
    - **多传感器融合**：利用雷达避障，利用视觉进行 ArucoTag 定位和物资识别。
        
- **侧重点**：**运动控制与环境感知**。如果你不想深入底层硬件，四足机器人的优势在于厂家已经把底层步态封装得很好，你更多是在 ROS 层面对其发送运动指令（如“上楼梯模式”）。

#### 8. 慧眼识果赛项：精准的“采摘工”

**定位**：属于**智慧农业（任务型）**。侧重于特定的视觉分类与物理执行。

- **赛项特性**：
    
    - **机械挑战**：要求机器人必须通过**剪断**果柄（PVC 绳）的方式采摘，禁止拽、拉、熔，这对末端执行器的结构设计提出了刚性要求。
        
    - **视觉任务**：区分红/绿果实，实现“完美植株”采摘（摘红留绿）。
        
- **侧重点**：**视觉分拣 + 精准机械切割**。适合擅长机械设计与颜色/空间位置识别的选手。
    

#### 9. 智慧果园赛项：具身的“农场主”

**定位**：属于**智慧农业（具身智能型）**。是慧眼识果的“进阶 AI 版”。

- **赛项特性**：
    
    - **交互创新**：通过与**本地大模型（LLM）**服务器交互，解析自然语言指令（如“采摘 2 号车位指定的成熟果实”），不再是写死的逻辑。
        
    - **形态要求**：要求设计**轮式底盘半人形**机器人，搭载双机械臂，模拟人类采摘动作。
        
- **侧重点**：**LLM 语义解析 + 纯视觉导航 + 双臂协同**。适合想尝试大模型驱动机器人任务流的算法选手。



### 赛题综合分类与核心能力图谱

为了方便你根据自身兴趣（不喜欢硬件、擅长逻辑等）进行选择，我将所有赛题进行了以下维度的分类：

### 维度 A：核心能力倾向

|**分类名称**|**能力重点**|**代表赛项**|
|---|---|---|
|**算法/逻辑驱动型**|视觉识别、LLM 交互、任务状态机、路径规划|**人形仿真**、**智慧果园**、**平安城市**|
|**机械/控制驱动型**|步态稳定性、越障能力、末端执行器机构设计|**四足巡检**、**物流小车**、**慧眼识果**|
|**方案/策略驱动型**|商业策划、对抗博弈策略、网络安全攻防|**人形比选**、**物流对抗组**、**人形安全**|

### 维度 B：比赛形式分类

1. **虚拟/方案赛（最适合“文职”算法选手）**：
    
    - **人形虚拟仿真**：纯代码，无需接触硬件。
        
    - **人形比选**：侧重方案与路演。
        
    - **人形安全（省赛）**：纯 CTF 线上夺旗。
        
2. **标准任务赛（自己跑自己的，相对稳定）**：
    
    - **平安城市**、**智慧零售**、**智慧果园**、**慧眼识果**。
        
    - 只要你的视觉和逻辑鲁棒性够好，硬件通常采用成熟平台，折腾少。
        
3. **竞技对抗赛（强身体对抗，硬件杀手）**：
    
    - **物流小车（对抗组）**：红蓝 1v1，容易发生碰撞和损毁。
