### 2.test train unsupervised分工
- **`train` (训练集, 25k)**：
    - **内容**：25,000 条带标签的评论（12,500 条正面，12,500 条负面）。
    - **用途**：**老师教课**。这是你现在做“情感分析”任务的主力数据。模型通过阅读这些评论和对应的标签（0或1），学习什么是“好评”，什么是“差评”。

- **`test` (测试集, 25k)**：
    - **内容**：另外 25,000 条带标签的评论。
    - **用途**：**期末考试**。这部分数据在训练过程中是绝对保密的。只有当模型训练好了，我们才用它来测试模型的真实水平，看它能不能准确判断从未见过的评论的情感。

- **`unsupervised` (无监督集, 50k)**：
    - **内容**：50,000 条**没有标签**的评论。我们只知道它们是电影评论，但不知道是褒是贬。
    - **用途**：**课外阅读（自学）**。
        - 这部分数据通常用于 **Masked Language Modeling (MLM)** 任务（也就是你之前文档里提到的第一步预训练）。
        - 模型通过大量阅读这些无标注文代，学习英语语法、表达习惯和电影领域的常用词（比如 "plot", "director", "acting"）。
        - 虽然你的 `clf`（分类）任务不需要它，但因为它是数据集“原生家庭”的一部分，Hugging Face 的加载器必须把它也下载下来才算“完整”。

```python
class Attention(nn.Module):
    def __init__(self, dim, num_heads=8, ...):
        # ...
        self.num_heads = num_heads
        # qkv 是 Query(查询), Key(钥匙), Value(值) 的缩写
        self.qkv = nn.Linear(dim, dim * 3, bias=qkv_bias) 
        # ...

    def forward(self, x):
        B, N, C = x.shape
        # 1. 算出 q, k, v
        qkv = self.qkv(x).reshape(B, N, 3, self.num_heads, C // self.num_heads).permute(2, 0, 3, 1, 4)
        q, k, v = qkv[0], qkv[1], qkv[2]

        # 2. 计算注意力分数 (Attention Scores)
        # q @ k.transpose: 查询去匹配钥匙，算出相关性。
        attn = (q @ k.transpose(-2, -1)) * self.scale
        attn = attn.softmax(dim=-1) # 归一化，变成概率（加起来等于1）
        
        # 3. 加权求和
        # (attn @ v): 根据相关性，把重要的 Value 加在一起，不重要的忽略。
        x = (attn @ v).transpose(1, 2).reshape(B, N, C)
        
        # 4. 最后的线性投影
        x = self.proj(x)
        return x, attn
```

## GelSight
基于视觉的触觉传感器 (Vision-based Tactile Sensors)
**1. 技术大类：基于视觉的触觉传感器 (Vision-based Tactile Sensors)

这是一个**技术类别**。它的共同特征是：

- **核心组件**：都包含一个弹性体（通常是硅胶）、光源（LED）和一个摄像头。
    
- **工作逻辑**：摄像头不去“看”外面的世界，而是专门“盯着”那块硅胶。当硅胶被物体按压变形时，摄像头记录下这种变形，并将其转化为图像。
    
- **优点**：分辨率极高，可以利用现成的计算机视觉（CV）算法来处理触觉信号。
    

**2. 具体传感器（品牌/型号）：GelSight, DIGIT 等

在这个大类下，有许多具体的设计和型号，就像“手机”是一个大类，而“iPhone”或“三星”是具体品牌：

- **GelSight**：这是最经典、最早成名的设计，主要特点是使用光度立体技术来还原超精细的 3D 表面。
    
- **DIGIT**：由 Meta (Facebook) 开发，设计更紧凑，适合装在机械手上。
    
- **GelSlim**：GelSight 的一种变体，外形更细长。
    
- **Taxim / TACTO**：这些是实验室在电脑里开发的“模拟器”，用来模拟上述硬件产生的图像。



更准确的层级关系是：

- **技术大类**：基于视觉的触觉传感器 (Vision-based Tactile Sensors)。
    
- **特定型号/家族**：**GelSight**（最著名的一种）、**DIGIT**（Meta 开发）、**GelSlim**（GelSight 的变体）等。
