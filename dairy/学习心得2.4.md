
# 安装激活conda环境
## 第一步：下载安装脚本

在终端执行以下命令，直接从清华大学开源镜像站下载（比官网快很多）：

Bash

```
wget https://mirrors.tuna.tsinghua.edu.cn/anaconda/miniconda/Miniconda3-latest-Linux-x86_64.sh
```

## 第二步：运行安装程序

下载完成后，运行这个脚本：

Bash

```
bash Miniconda3-latest-Linux-x86_64.sh
```

**安装时的注意事项：**

1. 看到协议时，按住 **Enter** 键往下翻，直到提示你输入 `yes`。
    
2. 询问安装路径时，直接按 **Enter**（默认安装在 `~/miniconda3`）。
    
3. **关键一步：** 结尾处会问你 `Do you wish the installer to initialize Miniconda3...`，请务必输入 **`yes`**。
    

## 第三步：激活 Conda

安装完成后，当前终端还识别不了。你需要刷一下配置文件：

Bash

```
source ~/.bashrc
```

此时，你的命令行开头应该会出现 `(base)` 字样，这说明 Conda 已经成功“附身”了。

---

## 第四步：创建你的 Python 3.9 环境

现在你再运行之前的命令（修正一下版本号写法）：

Bash

```
conda create -n py39 python=3.9
```
