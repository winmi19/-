
# DWM

不建议装在docker里面，因为外设的接口不好挂载，同时对opencv等库不支持，无法弹出窗口。延迟问题。

操作命令：

```
cd sdk  #sdk对应具体名字
```

```
pip install .  #安装路径下面的驱动和库
```

```
python main.py
```


# TSF （TS-E-A)

需要编译等一系列操作，容易出现错误。

去到自整理的文件夹下面

```
python D405_TSF_data_collect.py
```
